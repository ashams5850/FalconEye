## AI-Powered Smart Helmet for the Visually Impaired

FalconEye is an AI-powered smart helmet designed to assist visually impaired people in navigating their surroundings more safely and independently.

The system combines computer vision, voice interaction, ultrasonic sensing, GPS, and OCR to provide real-time environmental awareness and assistance.

### Key Features

- AI-based object detection
- Real-time obstacle detection
- Arabic voice assistant
- Bilingual OCR for reading text
- GPS-based location assistance
- Ultrasonic sensor fusion
- Offline processing using Raspberry Pi 5

### Hardware

- Raspberry Pi 5 (8GB)
- Raspberry Pi Camera
- Ultrasonic Sensors
- Speaker
- GPS Module
- Custom Power System

### Project Goal

The goal of FalconEye is to provide an affordable and practical assistive technology solution that helps visually impaired users better understand and interact with their surroundings.
